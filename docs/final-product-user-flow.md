# Final Product User Flow

Last updated: 2026-07-10

## 文件用途

本文件記錄 DrinkGroupBuy 最終成品預期的使用者操作流程。

這份文件是給使用者理解操作順序使用，不描述技術實作，也不代表目前程式碼已全部完成。

## 顧客操作

1. 打開 App。
2. 使用 Google 帳號登入。
3. 系統判斷顧客身份，進入顧客首頁。
4. 系統請求定位權限。
5. 顧客同意定位後，系統取得目前位置。
6. 系統依據顧客位置查詢附近店家與招募中的團購活動。
7. 系統於地圖或列表顯示店家與團購活動。
8. 顧客可拖曳、縮放地圖或設定篩選條件。
9. 系統依目前地圖範圍或篩選條件更新活動資訊。
10. 顧客點選想加入的團購活動，查看活動詳細資訊。
11. 顧客確認欲參與後，進入店家菜單頁面。
12. 系統顯示該店家可選購的飲品品項、分類、說明與價格。
13. 顧客點選飲品。
14. 顧客設定甜度、冰塊、加料與數量。
15. 顧客將飲品加入購物車。
16. 顧客可繼續選購其他飲品，或進入購物車頁面。
17. 系統顯示購物車明細、品項小計、訂單總額與目前團購進度。
18. 顧客確認訂單內容，或修改、刪除購物車品項。
19. 顧客選擇是否接受未達優惠時用原價購買。
20. 顧客確認無誤後送出訂單。
21. 系統建立訂單紀錄，並將該訂單納入團購活動統計。
22. 系統引導顧客前往 LINE Pay 付款或預授權流程。
23. 顧客完成付款或預授權流程後回到 App。
24. 系統依付款結果更新訂單付款狀態。
25. 系統更新團購活動目前累積杯數與活動進度。
26. 顧客可查看進行中訂單、團購進度與活動達標狀態。
27. 在訂單尚未鎖定前，顧客可修改訂單或取消參與。
28. 若訂單內容異動，系統重新計算訂單金額並更新付款狀態。
29. 若活動達標且店家確認接單，系統產生取貨憑證或取貨代碼。
30. 顧客依取貨時間到店取貨，並出示取貨憑證或取貨代碼。
31. 店家核銷後，系統更新訂單為已取貨。
32. 系統將完成的訂單保存至歷史訂單紀錄。

## 顧客退出團購

1. 進入我的訂單。
2. 選擇要退出的團購訂單。
3. 系統確認是否已進入截止前 30 分鐘。
4. 如果已進入截止前 30 分鐘，顧客不能退出團購。
5. 如果尚未進入截止前 30 分鐘，點選退出團購。
6. 確認退出。
7. 查看退出結果。

## 店家操作

1. 打開 App。
2. 使用 Google 帳號登入。
3. 系統判斷店家身份，進入店家預設畫面。
4. 查看目前進行中的團購活動、訂單數量、付款狀態與活動狀態。
5. 進入菜單管理。
6. 確認目前菜單內容。
7. 如需調整，修改飲料名稱、價格、甜度、冰塊、加料或是否開放販售。
8. 儲存菜單變更。
9. 點選建立團購。
10. 填寫團購名稱。
11. 設定截止時間。
12. 設定取餐時間。
13. 設定最低成團數量。
14. 設定優惠杯數門檻與折扣規則。
15. 選擇適用飲品。
16. 填寫活動備註。
17. 發布團購。
18. 系統建立團購活動，並將活動狀態設定為招募中。
19. 系統將團購同步顯示於顧客端地圖或活動列表。
20. 活動期間，查看目前累積杯數、訂單內容、付款狀態與達標情形。
21. 活動截止或達標後，確認是否接單。
22. 若確認接單，系統通知顧客並產生取貨憑證。
23. 開始製作飲料。
24. 製作完成後，標記可取餐。
25. 顧客到店取餐時，核對取貨憑證或取貨代碼。
26. 標記取餐完成。
27. 系統更新訂單取貨狀態。
28. 活動結束後，系統將活動狀態更新為已完成並保存紀錄。
29. 查看結算結果。

## 店家刪除或取消團購

1. 進入店家後台。
2. 選擇要處理的團購。
3. 如果尚未發布，點選刪除團購。
4. 如果已經發布，系統確認是否已進入截止前 30 分鐘。
5. 如果已進入截止前 30 分鐘，店家不能取消團購。
6. 如果尚未進入截止前 30 分鐘，點選取消團購。
7. 填寫或選擇取消原因。
8. 確認刪除或取消。
9. 查看處理結果。

## 四、店家團購與訂單管理

| 描述性綱目 | 事件條列式 |
| --- | --- |
| 店家登入後，可進入店家後台查看目前的團購活動、訂單數量、付款狀態與活動狀態。 | 店家 + 登入 + 查看店家後台 |
| 店家開啟團購前，可確認目前菜單內容，並視需要修改品項、價格、客製化選項與販售狀態。 | 店家 + 確認菜單 + 修改菜單 |
| 店家可建立團購，設定截止時間、取餐時間、優惠門檻、折扣規則、適用飲品與活動備註。 | 店家 + 建立團購 + 設定規則 |
| 店家可查看團購中的累積杯數、訂單內容、付款狀態與達標情形，並在截止或達標後確認是否接單。 | 店家 + 查看活動 + 確認接單 |
| 店家確認接單後，系統通知顧客並產生取貨憑證，店家完成製作後可標記可取餐。 | 店家 + 確認接單 + 標記可取餐 |
| 顧客到店取餐時，店家可依取貨憑證或取貨代碼核銷訂單，並更新取貨狀態。 | 店家 + 核銷取貨 + 更新訂單 |
| 店家可刪除尚未發布的團購，或取消已發布的團購並處理相關訂單與付款狀態。 | 店家 + 取消團購 + 更新狀態 |
| 活動結束後，系統將活動狀態更新為已完成並保存紀錄，店家可查看結算結果。 | 店家 + 完成活動 + 查看結算 |
