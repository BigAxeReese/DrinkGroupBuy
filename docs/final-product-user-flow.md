# Final Product User Flow

Last updated: 2026-07-10

## 文件用途

本文件記錄 DrinkGroupBuy 最終成品預期的使用者操作流程。

這份文件是給使用者理解操作順序使用，不描述技術實作，也不代表目前程式碼已全部完成。

## 顧客操作

1. 打開 App。
2. 使用 Google 帳號登入。
3. 系統判斷顧客身份，進入顧客首頁。
4. 系統請求定位權限。
5. 顧客同意定位後，系統取得目前位置。
6. 系統依據顧客位置查詢附近店家與招募中的團購活動。
7. 系統於地圖或列表顯示店家與團購活動。
8. 顧客可拖曳、縮放地圖或設定篩選條件。
9. 系統依目前地圖範圍或篩選條件更新活動資訊。
10. 顧客點選想加入的團購活動，查看活動詳細資訊。
11. 顧客確認欲參與後，進入店家菜單頁面。
12. 系統顯示該店家可選購的飲品品項、分類、說明與價格。
13. 顧客點選飲品。
14. 顧客設定甜度、冰塊、加料與數量。
15. 顧客將飲品加入購物車。
16. 顧客可繼續選購其他飲品，或進入購物車頁面。
17. 系統顯示購物車明細、品項小計、訂單總額與目前團購進度。
18. 顧客確認訂單內容，或修改、刪除購物車品項。
19. 顧客選擇是否接受未達優惠時用原價購買。
20. 顧客確認無誤後送出訂單。
21. 系統建立訂單紀錄。
22. 系統引導顧客前往 LINE Pay 預授權流程。
23. 顧客完成預授權流程後回到 App。
24. 系統依預授權結果更新訂單付款狀態。
25. 預授權成功後，該訂單自動成立並納入團購活動統計。
26. 系統將該訂單杯數計入團購達標杯數，並更新活動進度。
27. 系統通知店家有新訂單，並將訂單加入店家製作清單。
28. 顧客可查看進行中訂單、團購進度與活動達標狀態。
29. 在訂單尚未鎖定前，顧客可修改訂單或取消參與。
30. 若訂單內容異動，系統重新計算訂單金額並更新付款狀態。
31. 進入截止前 30 分鐘後，顧客不能修改訂單，也不能退出團購。
32. 若活動達標，系統產生取貨憑證或取貨代碼。
33. 顧客依取貨時間到店取貨，並出示取貨憑證或取貨代碼。
34. 店家核銷後，系統更新訂單為已取貨。
35. 系統將完成的訂單保存至歷史訂單紀錄。

## 顧客退出團購

1. 進入我的訂單。
2. 選擇要退出的團購訂單。
3. 系統確認是否已進入截止前 30 分鐘。
4. 如果已進入截止前 30 分鐘，顧客不能修改訂單，也不能退出團購。
5. 如果尚未進入截止前 30 分鐘，顧客可修改訂單或點選退出團購。
6. 確認退出。
7. 查看退出結果。

## 店家菜單與開團管理

1. 打開 App。
2. 使用 Google 帳號登入。
3. 系統判斷店家身份，進入店家預設畫面。
4. 查看目前進行中的團購活動、訂單數量、付款狀態與活動狀態。
5. 進入菜單管理。
6. 確認目前菜單內容。
7. 如需調整，修改飲料名稱、價格、甜度、冰塊、加料或是否開放販售。
8. 儲存菜單變更。
9. 點選建立團購。
10. 填寫團購名稱。
11. 設定截止時間。
12. 設定取餐時間。
13. 設定最低成團數量。
14. 設定優惠杯數門檻與折扣規則。
15. 選擇適用飲品。
16. 填寫活動備註。
17. 發布團購。
18. 系統建立團購活動，並將活動狀態設定為招募中。
19. 系統將團購同步顯示於顧客端地圖或活動列表。
20. 如果團購尚未發布且不需要保留，店家可刪除該團購草稿。

## 店家訂單與履約管理

1. 進入店家後台。
2. 查看目前進行中的團購活動、訂單數量、付款狀態與活動狀態。
3. 活動期間，查看目前累積杯數、訂單內容、付款狀態與達標情形。
4. 顧客完成預授權後，系統自動將訂單納入團購活動統計，並加入店家製作清單。
5. 店家查看製作清單。
6. 若店家發現缺料或無法製作，可回報異常原因。
7. 系統依異常處理結果通知顧客改選、取消或等待管理員處理。
8. 如果店家需要取消已發布團購，系統確認是否已進入截止前 30 分鐘。
9. 如果已進入截止前 30 分鐘，店家不能取消團購。
10. 如果尚未進入截止前 30 分鐘，店家可點選取消團購。
11. 店家填寫或選擇取消原因。
12. 系統處理相關訂單與付款狀態。
13. 活動達標後，系統通知顧客並產生取貨憑證。
14. 店家開始製作飲料。
15. 製作完成後，店家標記可取餐。
16. 顧客到店取餐時，店家核對取貨憑證或取貨代碼。
17. 店家標記取餐完成。
18. 系統更新訂單取貨狀態。
19. 活動結束後，系統將活動狀態更新為已完成並保存紀錄。
20. 店家查看結算結果。

## 二、顧客點餐與購物車

| 描述性綱目 | 事件條列式 |
| --- | --- |
| 顧客可查看店家可選購的飲品品項、分類、說明與價格。 | 顧客 + 瀏覽 + 飲料菜單 |
| 顧客可選擇飲品，並設定甜度、冰塊、加料與數量。 | 顧客 + 選擇飲品 + 設定內容 |
| 顧客完成設定後，可將飲品加入購物車、繼續選購，並查看明細、品項小計、訂單總額與團購進度。 | 顧客 + 加入購物車 + 確認金額 |
| 顧客可修改或刪除購物車品項，並選擇未達優惠時是否接受原價購買後確認訂單。 | 顧客 + 修改購物車 + 確認訂單 |

## 三、顧客訂單與團購管理

| 描述性綱目 | 事件條列式 |
| --- | --- |
| 顧客確認購物車後送出訂單，系統建立訂單紀錄，並引導顧客前往 LINE Pay 預授權。 | 顧客 + 送出訂單 + 前往預授權 |
| 預授權成功後，訂單自動成立並納入團購統計；系統更新杯數、活動進度，並通知店家加入製作清單。 | 系統 + 預授權成功 + 更新進度 |
| 顧客可查看進行中訂單與團購進度；訂單尚未鎖定前可修改或退出，異動後系統重新計算金額與付款狀態。 | 顧客 + 查看訂單 + 修改訂單 |
| 顧客修改訂單或退出前，系統需確認是否已進入截止前 30 分鐘；活動達標後產生取貨憑證，取貨完成後保存紀錄。 | 顧客 + 檢查鎖定 + 完成取貨 |

## 四、店家菜單與開團管理

| 描述性綱目 | 事件條列式 |
| --- | --- |
| 店家登入後，可進入店家後台查看目前的團購活動、訂單數量、付款狀態與活動狀態。 | 店家 + 登入 + 查看店家後台 |
| 店家開啟團購前，可確認目前菜單內容，並視需要修改品項、價格、客製化選項與販售狀態。 | 店家 + 確認菜單 + 修改菜單 |
| 店家可建立團購，設定截止時間、取餐時間、優惠門檻、折扣規則、適用飲品與活動備註。 | 店家 + 建立團購 + 設定規則 |
| 店家發布團購後，系統建立團購活動並同步顯示於顧客端；如果團購尚未發布，店家可刪除草稿。 | 店家 + 發布或刪除 + 更新狀態 |
