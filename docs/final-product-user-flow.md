# Final Product User Flow

Last updated: 2026-07-09

## 文件用途

本文件記錄 DrinkGroupBuy 最終成品預期的使用者操作流程。

這份文件是給使用者理解操作順序使用，不描述技術實作，也不代表目前程式碼已全部完成。

## 顧客操作

1. 打開 App。
2. 使用 Google 帳號登入。
3. 選擇想加入的團購。
4. 選擇飲料。
5. 選擇甜度、冰塊、加料與數量。
6. 加入購物車。
7. 進入購物車確認品項。
8. 選擇是否接受未達優惠時用原價購買。
9. 送出訂單。
10. 前往付款。
11. 付款完成後回到 App。
12. 查看團購進度。
13. 等待店家製作。
14. 店家通知可取餐後，前往取餐。
15. 取餐完成。

## 顧客退出團購

1. 進入我的訂單。
2. 選擇要退出的團購訂單。
3. 點選退出團購。
4. 確認退出。
5. 查看退出結果。

## 店家操作

1. 打開 App。
2. 使用 Google 帳號登入。
3. 進入店家預設畫面。
4. 點選建立團購。
5. 填寫團購名稱。
6. 設定截止時間。
7. 設定取餐時間。
8. 設定最低成團數量。
9. 設定優惠規則。
10. 發布團購。
11. 查看顧客訂單。
12. 團購截止後，確認訂單。
13. 開始製作飲料。
14. 製作完成後，標記可取餐。
15. 顧客取餐時，核對取餐資訊。
16. 標記取餐完成。
17. 查看結算結果。

## 店家刪除或取消團購

1. 進入店家後台。
2. 選擇要處理的團購。
3. 如果尚未發布，點選刪除團購。
4. 如果已經發布，點選取消團購。
5. 填寫或選擇取消原因。
6. 確認刪除或取消。
7. 查看處理結果。

## 一、顧客瀏覽與選擇團購

| 描述性綱目 | 事件條列式 |
| --- | --- |
| 顧客登入後，可查看附近正在進行的團購活動。 | 顧客 + 登入 + 查看附近團購 |
| 顧客可從列表或地圖中選擇想加入的團購。 | 顧客 + 查看團購 + 選擇團購 |
| 顧客可查看團購的基本資訊，確認是否要加入。 | 顧客 + 查看 + 團購資訊 |
| 顧客決定加入後，可進入該店家的飲料選購流程。 | 顧客 + 點選團購 + 進入選購 |

## 二、顧客點餐與購物車

| 描述性綱目 | 事件條列式 |
| --- | --- |
| 顧客可查看店家提供的飲料品項。 | 顧客 + 瀏覽 + 飲料菜單 |
| 顧客可選擇飲料，並設定甜度、冰塊、加料與數量。 | 顧客 + 選擇飲料 + 設定內容 |
| 顧客完成設定後，可將飲料加入購物車。 | 顧客 + 加入購物車 + 繼續選購 |
| 顧客可在購物車中確認品項、數量與金額。 | 顧客 + 查看購物車 + 確認內容 |

## 三、顧客訂單與團購管理

| 描述性綱目 | 事件條列式 |
| --- | --- |
| 顧客確認購物車後，可送出訂單並前往付款。 | 顧客 + 送出訂單 + 前往付款 |
| 顧客付款完成後，可查看團購進度與訂單狀態。 | 顧客 + 付款完成 + 查看團購進度 |
| 顧客可在自己的訂單中查看進行中訂單與歷史訂單。 | 顧客 + 查看 + 我的訂單 |
| 顧客可在允許的時間內退出團購。 | 顧客 + 退出團購 + 查看結果 |

## 四、店家團購與訂單管理

| 描述性綱目 | 事件條列式 |
| --- | --- |
| 店家登入後，可進入店家後台查看目前的團購活動。 | 店家 + 登入 + 查看店家後台 |
| 店家可建立團購，設定截止時間、取餐時間與優惠規則。 | 店家 + 建立團購 + 設定規則 |
| 店家可查看團購中的顧客訂單，並在截止後確認製作內容。 | 店家 + 查看訂單 + 確認製作 |
| 店家可標記可取餐，也可刪除或取消不繼續的團購。 | 店家 + 處理團購 + 更新狀態 |
