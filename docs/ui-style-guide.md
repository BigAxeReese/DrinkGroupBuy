# UI 視覺風格指南

最後更新：2026-09-20

## 決定

- 風格方向：**奶茶上色**。顏色取自飲料：奶茶色、珍珠黑、黑糖褐、抹茶綠、芋頭紫。
- **App 內不使用藍色。** 藍色只留在桌面圖示（`mobile/assets/icon.png`）與登入插圖（`mobile/assets/login-hero.png`）。（2026-09-20：使用者比較深鈷藍、淺藍、霧藍、黑糖褐四組後，選定黑糖褐。）
- 第一版**不新增任何套件**：只用 React Native 內建元件與系統字型；底部導覽用「圓點＋文字」，小圖形用 View 拼。
- 目前只有決定與設定值，**還沒有套用到任何畫面**（見「導入順序」）。

數值（色碼、字級、圓角）以 [`mobile/src/theme/tokens.js`](../mobile/src/theme/tokens.js) 與 [`statusTones.js`](../mobile/src/theme/statusTones.js) 為準；[`mobile/tests/themeTokens.test.mjs`](../mobile/tests/themeTokens.test.mjs) 會自動檢查對比度與狀態對照。本文件只說規則與原因。

## 原則

1. **每一種顏色只管一件事。**
2. **全 App 只有 2px 一種線粗。** 實心黑糖褐＝可以按；白底加 2px 黑糖褐外框＝畫出來的線稿，或「目前被選中」的東西。
3. **整個 App 是平的**：不用陰影、漸層、濾鏡。只有蓋在畫面上方的東西（底部彈窗、提示條）用 Android 原生的浮起效果（elevation）。
4. **中文字只用一般（400）與粗體（700）兩種粗細。** 各家手機的中文字型不同，其他粗細不保證有效；層次靠字級、顏色、留白。
5. **意思不只靠顏色。** 每個狀態標籤都有文字，再加一個小記號：勾＝成功、三點＝進行中、驚嘆號＝留意、叉＝失敗、短橫線＝已結束。
6. **大字要設上限。** 取餐碼、珍珠數字、標籤加 `maxFontSizeMultiplier`（1.1），避免使用者調大系統字體時版面爆掉；固定高度一律改 `minHeight`。

## 顏色

對比度＝兩個顏色看起來差多少。文字要 ≥ 4.5，畫出來的線要 ≥ 3。

| 名稱（設定值名稱） | 色碼 | 用途 | 對比度 |
| --- | --- | --- | --- |
| 鮮奶白（`page`） | `#FFFFFF` | 頁面與卡片的底 | — |
| 奶茶（`recess`） | `#F3E4D2` | 凹槽：珍珠盤底板、未選的標籤、次要面板 | — |
| 珍珠黑（`text`） | `#2A1B17` | 主要文字、實心珍珠、取餐碼面板 | 白底 16.57、奶茶底 13.28 |
| 黑糖灰（`textSecondary`） | `#6F5A4E` | 次要文字（只放白底或奶茶底） | 6.46／5.18 |
| 黑糖褐（`accent`） | `#8B5E3C` | 可以按的實心底（配白字）、2px 畫出來的線 | 白字 5.58；線：白底 5.58、奶茶底 4.47 |
| 深褐（`accentInk`） | `#6B4423` | 連結、被選中的標籤文字 | 8.48／6.80 |
| 米白（`onDark`） | `#FFF8F2` | 取餐碼面板上的字 | 15.75 |
| 輸入框線（`lineInput`） | `#A38670` | 未選取的輸入框外框 | 白底 3.39 |
| 裝飾線（`lineDecor`、`lineRow`） | `#EADBCB`、`#C9B39C` | 顧客卡片外框、商家列與列之間的 1px 線；純裝飾，不承載意思 | 1.36、2.02（不要求） |

## 狀態標籤

| 色調 | 底／字 | 記號 | 用在 |
| --- | --- | --- | --- |
| 進行中（焦糖，`info`） | `#E8CDAE`／`#5A3818` | 三點 | 招募中、訂單製作中、**訂單成立（已授權、還沒扣款）** |
| 成功／已鎖定（抹茶綠，`success`） | `#E5F0D3`／`#2F5A14` | 勾 | 已成團、可取餐、**已付款** |
| 留意（淡黃，`warning`） | `#FBEBC8`／`#7A4A00` | 驚嘆號 | 已額滿、待付款、待審核 |
| 失敗（粉紅，`danger`） | `#FBE3E6`／`#9E1F3A` | 叉 | 流團、扣款失敗、已逾期、已駁回 |
| 已結束（冷灰，`neutral`） | `#ECEAE8`／`#4F4A46` | 短橫線 | 已完成、已取消、已退款 |
| 預估（芋頭紫，`estimate`） | `#EFE8F7`／`#5B3D8C` | 三點 | 尚未達標、還會變動的折扣；結算後換成抹茶綠 |

33 種狀態的完整對照在 `statusTones.js`。**「訂單成立」（只預留額度）與「已付款」（真的扣了）不可以用同一種色調**，有測試守著。

## 字級與形狀

- 字級（px，字／行高）：珍珠數字 32／36、取餐碼 52／60、頁面標題 24／32、區塊標題 17／24、價格 18／24、按鈕 16／22、內文 15／23（商家密集畫面 14／20）、標籤 12／16、說明 12／17。
- 圓角：8（標籤內小塊）、14（輸入框）、20（商家卡片）、28（顧客卡片、珍珠盤、取餐面板）、999（按鈕、狀態標籤、珍珠）。按鈕高 52、圓角 26；可點的東西高度至少 44。
- 間距以 4 為單位（4／8／12／16／20／24／32）。顧客畫面左右留 20、卡片內距 20；商家與其他密集畫面左右留 14 到 16、列高 56。

## 招牌元件：當級珍珠盤

- 一顆珍珠＝一杯。實心珍珠黑＝已訂；2px 黑糖褐空圈＝還沒人訂的名額。級距很大時一顆代表多杯，旁邊的文字永遠寫精確杯數。
- 只畫「你現在這一級」。下方的級距階梯每級一列：預估用芋頭紫，結算鎖定後換抹茶綠。
- 填幾顆的規則（實作時寫成純函式並加測試）：0 杯＝0 顆；達到級距＝全滿；其餘取「無條件捨去、至少 1 顆、最多留 1 個空位」，避免 99／100 杯看起來已經滿了。
- 用在：團購詳情與進度（大盤加階梯）、首頁卡片（迷你 5 顆）、取餐憑證（領幾杯就幾顆）、商家製作清單（杯數圓盤，維持唯讀）。

## 導入順序

1. **（已完成）** 本文件、設定值、對比度測試。不改任何畫面。
2. 把畫面裡寫死的顏色（`mobile/src` 共 565 處、32 個檔案，2026-09-20 統計）換成設定值。先讓設定值「等於現在的外觀」，逐檔機械替換，畫面完全不變，逐檔用 diff 確認。前提：目前未提交的修改先處理，避免混進同一份 diff。
3. 一個提交把設定值換成新配色，同時換共用元件（`PrimaryButton`、`MobileScreen`／`Section`、`StatusBadge`、`BottomNav`）。順便處理：首頁與商家儀表板兩處用負邊距做的滿版標頭（`NearbyGroupBuyActivitiesScreen.jsx:212`、`MerchantDashboardScreen.jsx:646`）改成一般標題列；現在的頁面底色 `#f6f8fb`（`App.jsx`、`AppNavigator.js`）改成 `page`。
4. 珍珠盤：`ProgressSummary`、`DiscountSummaryCard`、首頁進度條。先在真的 Android 手機上確認排版（窄螢幕、調大字體），最好兩個不同廠牌，再往下。
5. 各畫面逐一換皮（顧客 → 商家）。付款相關畫面換皮後，依專案規定新增一筆 `docs/AI-security-review-log.md`。
6. 登入插圖重新上色成黑糖褐；桌面圖示與啟動畫面底色（`app.config.js`，原生設定，OTA 更新無法改）等下一次本來就要打包時一起換。

## 未決事項與已知風險

- 黑糖褐版本是使用者選定後的變形，**沒有經過先前的多方評審**，只做過對比度與色差計算。
- 淡色標籤彼此色差偏小（最小 8.4，例如「失敗」粉紅與「已結束」冷灰），主要靠文字與記號分辨；上實機後要再確認。
- 付款文案是否把「授權」「請款」改成「預留額度」「扣款」：尚未決定，不在本次範圍。
- 導覽圖示：先用「圓點＋文字」。之後若要圖示，需新增套件，或自己畫透明底 PNG（現有兩張品牌 PNG 完全不透明，不能直接染色）。
- 登入插圖與桌面圖示仍是藍色，在換色之前會和 App 內的黑糖褐不搭。

## 設計預覽

[`docs/ui-style-previews/`](ui-style-previews/) 是選定風格前的比較稿，單一 HTML 檔、直接用瀏覽器開，只是網頁模擬，不是真的 App：

- `direction-A.html`：一筆珍珠（線稿延伸）。`direction-B.html`：杯貼取餐券。`direction-C.html`：奶茶上色，原本的深鈷藍版（這個藍已被否決）。三個是評審後的入圍方向。
- `blue-options.html`：同一個團購詳情畫面套 4 組藍色（深鈷藍、淺藍、霧藍、黑糖褐）。**最右邊「④ 不用藍」就是最後選定的樣子**；它的「進行中」標籤已改成修正後的焦糖色（原稿用奶茶色，跟凹槽一樣，色差 0）。

這些是決策紀錄，**不隨程式更新**；實際數值以 `tokens.js` 為準。

## 不做的事

- 暗色模式（專案目前只有淺色）。
- 新增套件，包含數字專用的圓頭字型（需要 `expo-font`）。
- 新功能：商家製作清單「逐杯打勾」、首頁「清單／地圖」切換。這次只換外觀。
