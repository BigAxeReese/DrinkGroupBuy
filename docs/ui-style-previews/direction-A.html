一筆珍珠One-Stroke Pearl (Monoline)

整個 App 用同一支筆畫出來：一種線條粗細、一種墨藍、一張白紙，跟你的杯子 Logo 和登入插圖一樣。每有人訂一杯，就有一顆珍珠被填滿；虛線代表「還會變」，實線代表「已經定了」，所以「只預留額度、還沒扣款」是被畫出來的，不只是寫出來的。

簽名元件：一杯一珠進度盤（Pearl Tray）
9折虛線章＝預估，實心章＝定案

下面是四個 360dp 寬的模擬手機畫面，可以左右滑動。所有效果都是 React Native 內建元件做得到的：實線、虛線、圓角、旋轉，沒有陰影、漸層、外部字型。

6. 優點、缺點與技術等級

優點
  • 最貼近你現有的杯子 Logo 與登入插圖，整個 App 像同一支筆畫的。
  • 用虛線與實線把「還沒扣款」和「已經定了」畫出來，錢的畫面最安心。
  • 完全不需要新套件、不用陰影，技術風險最低，也最容易一小步一小步上線。
缺點
  • 整個 App 只有一種藍，可能像銀行 App，要靠珍珠與口氣撐出個性。
  • 導覽圖示的 PNG 要有人畫，畫之前先用圓點加文字撐著。
  • 虛線在 Android 實機的樣子還沒驗證，第一個切片就要先在真機看。

適合你的情況：想要最貼近現有品牌、最好分小步上線、又要把「授權不等於扣款」講清楚的話，選這個。

選配升級（都要你先同意才會新增）

需新增套件@expo/vector-icons（只用 Feather 那組）＋ expo-font：商家頁圖示越來越多時，不用一張一張畫 PNG。
需新增套件@expo-google-fonts/nunito ＋ expo-font（低優先）：圓頭英數字體，只用在大數字與取餐碼。
