杯貼取餐券 Cup-Label Voucher

取餐碼是要給店員看的憑證，所以做成一張像杯貼的票根：票身列出店名、品名、甜度、冰塊、數量，票根放全畫面最重要的數字。只有三張票是暖色紙，其他畫面都是白色卡片放在冷色櫃台上，該蓋章的時刻才蓋章。

招牌元素：杯貼取餐券（Voucher Stub）　第 0 層：只用 React Native 內建元件，不需新增套件

色盤：冷色櫃台、白卡片、三張暖色紙

五種語意色調（底／字／邊）

字級（中文只用 400 與 700）

票上數字（取餐碼、杯數、金額）用系統等寬字，像熱感紙印出來；其他數字用粗體加等寬數字（tabular-nums）。選配升級：只含數字的等寬字型 IBM Plex Mono 子集 需新增套件（expo-font），本稿一律退回同一組系統字型。

狀態貼紙全表（每一種都附文字，顏色不單獨表意）

「訂單成立」旁固定一個虛線標籤：尚未扣款，截止後才扣款；只有「已付款」之後才出現收據。

優缺點

優點

  • 取餐票像真的杯貼，造型跟「給店員看的憑證」是同一件事，最有記憶點。
  • 商家製作清單依飲料分組加標題帶，三個方向裡最好掃。
  • 虛線只放在真的能撕的地方、印章一畫面最多一個，克制不花俏。

缺點

  • 要做票券、撕線、缺口、印章三個新元件，還要補圖示，工作量最大。
  • 暖色紙與冷色櫃台的亮度差小，強光下卡片邊界要靠外框撐。
  • 有滑向復古票券或兒童貼紙簿的風險，要靠只用三處來控管。

適合：想讓「取餐」這個動作最有儀式感、願意多花力氣做票券元件的話，選這個。
