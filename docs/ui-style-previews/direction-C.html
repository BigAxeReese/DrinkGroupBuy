方向 C・UI 風格提案

奶茶上色Milk Tea, Coloured In

App 的顏色來自杯子裡的東西：珍珠黑當字、奶茶色當凹槽、抹茶綠代表已鎖定、芋頭紫代表預估。品牌藍是畫杯子的那支筆，畫出線稿、畫出被選中的東西；杯子的線稿進到 App 之後被「上了色」。

招牌元素：當級珍珠盤（Tier Tray）

這是網頁模擬，不是真的 App。所有畫面只用 React Native 內建功能做得出來（不新增任何套件）。

四個畫面

左右捲動可看完四支手機；每支手機的內容可以上下捲動。螢幕寬度以 360dp（Android 常見寬度）計算。

圓角與線條

8　標籤內小塊14　輸入框20　商家卡片28　顧客卡片999　按鈕

全 App 只有 2px 一種線粗。實心杯線藍＝可以按；2px 藍外框＝畫出來的線稿或目前被選中的東西。整個 App 是平的，不用陰影、漸層、濾鏡；只有蓋在畫面上方的東西（底部彈窗、提示條）用一層 Android 原生 elevation（浮起高度）。

優點與缺點

優點

  • 顏色從飲料裡來（奶茶、珍珠、抹茶、芋頭），最有食慾、最有生活感。
  • 預估用芋頭紫、定案換抹茶綠，顏色一變就知道「鎖定了」。
  • 導覽用圓點加文字，完全不需要圖示檔，素材風險最低。

缺點與風險

  • 暖色系容易被看成「又一個手搖飲 App」，藍色 Logo 的連續感比 A 弱。
  • 顏色種類多（藍、紫、綠、琥珀、紅、褐），要有紀律地各管一件事。
  • 珍珠一顆代表多杯時，要看商家實際設定好不好懂。

適合：想讓 App 看起來像飲料、親切好入口，又願意接受品牌藍退到「筆」的角色。覺得顏色太雜，就先砍芋頭紫（預估折扣退回資訊藍）。
